Who built it? *
Try it (optional) Add a link only if you want other people to use or test your project.
Before you share a link, protect your costs and data. Anyone who has the link can use your project, and every use can spend your tokens, API requests or free-tier quota. So:
  • Set spending caps or usage limits on every paid tool and API key you use.
  • Keep API keys out of your code and public repositories; store them as environment variables.
  • Add a request limit or a sign-in so one person can’t use up your quota.
  • Don’t expose personal or sensitive data.
  • Start with a small group of testers. You can take the link down at any time.
